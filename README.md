# Actividad formativa 2: Simulación y análisis de señales con la Transformada de Fourier

## Descripción
Este proyecto tiene como objetivo analizar señales en los dominios del tiempo y la frecuencia mediante Python y la Transformada Rápida de Fourier (FFT).

## Objetivos
- Generar y representar señales elementales.
- Calcular los espectros de magnitud y fase.
- Analizar las propiedades de linealidad, desplazamiento temporal y escalamiento temporal.
- Interpretar los resultados obtenidos mediante gráficas.

## Señales analizadas
- Pulso rectangular.
- Función escalón.
- Señal sinusoidal de 5 Hz.

## Herramientas utilizadas
- Python
- NumPy
- Matplotlib
- Google Colab

## Archivo principal
`Actividad2_Transformada_Fourier.ipynb`

El notebook contiene el código utilizado para generar las señales, calcular la FFT, representar los espectros y comprobar algunas propiedades de la Transformada de Fourier.

## Resultados
Se obtuvieron gráficas de las señales en el dominio del tiempo y de sus espectros de magnitud y fase. También se verificó numéricamente la propiedad de linealidad y se observó el efecto de la compresión temporal sobre la frecuencia de una señal sinusoidal.

## Ejecución
El archivo `.ipynb` puede abrirse directamente en Google Colab o en un entorno Jupyter Notebook con Python, NumPy y Matplotlib instalados.
